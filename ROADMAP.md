# Roadmap

Ideas queued for later versions.

## Later

- **Gap per app.** Give specific apps their own margins (e.g. a narrower gap for a terminal,
  a wider one for a browser), building on the "Never resize" list.
- **Custom shortcuts.** Let people record their own shortcut instead of the fixed ⌃⌥⌘F, and add
  a second one to fit every window on the current display.
- **Fit only the first window.** Option to fit only an app's first window and let later windows
  keep the size the app remembers.
